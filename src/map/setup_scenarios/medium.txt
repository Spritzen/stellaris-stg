# medium.txt — INTENTIONALLY DECLARES NOTHING.
#
# STG ships The Known Galaxy and the picker offers nothing else
# (.docs/decisions/88-lock-the-galaxy-picker.md). It comes in three SIZES as of
# 2026-09-01 -- 95 / 600 / 1,000 systems, one generator, three scenario files
# (.docs/decisions/111-three-galaxy-sizes.md) -- so the picker offers a choice
# of size and never a choice of shape, and vanilla's five sizes are still the
# wrong five to offer. This file exists to REMOVE
# vanilla's `medium` galaxy size from the setup screen: a scenario is
# offered because a file at this path declares it, so the way to withdraw one
# is to occupy the path and declare nothing.
#
# It shadows BOTH vanilla's `medium.txt` and Yet Another Galaxy Enhancement
# Mod's override of it. Excluding YAGEM's copy in vendor.yml would not do --
# vanilla's own would simply load in its place.
#
# STNH does this with five 0-byte files at exactly these five paths. STG uses a
# comment-only file instead, which the parser treats identically and which can
# say why it is here. Vanilla's own `static_galaxy_example.txt` is the
# precedent for a scenario file that is entirely comments and declares nothing.
#
# Nothing to regenerate: this file has no content to fall out of date.
