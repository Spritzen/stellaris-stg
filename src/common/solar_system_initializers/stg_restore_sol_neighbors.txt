# Restores the ten Sol-neighbour initializers Real Space 4.0 drops.
#
# Real Space's copy of common/solar_system_initializers/sol_initializers.txt
# shadows vanilla's path and replaces vanilla's generic `sol_neighbor_t*`
# systems with real stars (Alpha Centauri, Barnard's Star, Sirius, Procyon).
# Planetary Diversity still references three of the dropped keys, so the engine
# threw `Invalid initializer` four times per run and those neighbour systems
# were never generated.
#
# Additive, not a shadow: Real Space's file declares none of these keys, so
# nothing here contests it and its real-star systems are untouched.
#
# Bodies are vanilla's verbatim except that vanilla's file-local @distance (50),
# @base_moon_distance (10) and @jumps (3) are substituted as literals — this
# file cannot inherit them and redeclaring them would add to the
# `Variable name ... is already taken` noise this directory already produces.
#
# See .docs/decisions/38-real-space-drops-sol-neighbours.md.
