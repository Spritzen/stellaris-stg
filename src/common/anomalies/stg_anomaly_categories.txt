# Star Trek Galaxies -- Trek anomaly categories.
#
# A NEW file, not a shadow: anomaly categories merge by key across files, so
# vanilla's 137 are untouched and these 21 are added beside them. Outcome events
# are in events/stg_anomaly_events.txt, pictures in
# interface/stg_event_pictures.gfx, names and descriptions in
# localisation/english/stg_anomalies_l_english.yml -- four halves that must all
# meet, which is what check_anomalies asks.
#
# Every trigger, reward tier and idiom here is copied from
# common/anomalies/00_anomaly_categories.txt and events/anomaly_events_*.txt.
# Yardstick: vanilla's base game ships 40 categories in that file.
# See .docs/decisions/75-trek-anomalies.md
