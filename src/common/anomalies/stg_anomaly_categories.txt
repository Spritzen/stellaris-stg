# Star Trek Galaxies -- Trek anomaly categories.
#
# A NEW file, not a shadow: anomaly categories merge by key across files, so
# vanilla's 327 are untouched and these 21 are added beside them. Outcome events
# are in events/stg_anomaly_events.txt, pictures in
# interface/stg_event_pictures.gfx, names and descriptions in
# localisation/english/stg_anomalies_l_english.yml -- four halves that must all
# meet, which is what check_anomalies asks.
#
# Every trigger, reward tier and idiom here is copied from
# common/anomalies/00_anomaly_categories.txt and events/anomaly_events_*.txt.
# Yardstick: vanilla's base game ships 40 categories in that file.
#
# NINE OF THE 21 ARE RESTRICTED -- five `max_once_global` (planet_killer_remnant,
# iconian_gateway, tox_uthat, deep_space_probe, omega_signature) and four
# `max_once` (resonator_cache, living_ship, cetacean_probe, transwarp_conduit).
# The rule is the one decision 70 states -- a category that names a SPECIFIC
# thing is restricted, one that names a KIND of thing is not -- but the tally
# there says seven. It is nine, which is 43% against vanilla's base-game 8 of 40,
# and that is a consequence of a Trek set naming more specific objects rather
# than a drift from the rule.
# See .docs/decisions/73-phase-4-count-corrections.md
#
# THE SPAWN WEIGHTS WERE RAISED 2026-08-29 -- 1 -> 2, 2 -> 3, 3 -> 5, all 33 of
# them, every value a vanilla idiom (vanilla writes `add = 3` 143 times, 2 15
# times, 5 11 times). These 21 categories held 5.3% of the merged pool's spawn
# weight where their share of its spawnable categories is 8.4%: written a notch
# stingier than vanilla in EVERY body class, not in one. The remap lands at
# 8.3%, and per class within a point or two of fair share. Do not read the raw
# ratio without excluding vanilla's four `add >= 100` scene-specific spawns --
# DISTAR_DEAD_GOD_CAT alone is `add = 1000` and it made the same gap look three
# times worse than it is.
#
# THE LEVELS WERE DELIBERATELY LEFT ALONE, and the measurement is why: these
# categories lean hard, 43% of them at level 5+, but they are 8% of the pool, so
# the galaxy a player actually surveys goes from vanilla's 25.2% of spawn weight
# at level 5+ to 27.4%. Two points. The skew is content -- an Iconian gateway is
# meant to be hard -- and it is not a difficulty problem.
# See .docs/decisions/108-anomaly-weights-not-levels.md
#
# EVERY CATEGORY NEEDS A POSITIVE `spawn_chance`. It defaults to `base = 0`, and
# a category with nothing adding to it is complete, validating clean and never
# rolled. check_anomalies asks this now; a `factor` does not count, because it
# multiplies. See .docs/decisions/74-reachability-checks.md
#
# See .docs/decisions/70-trek-anomalies.md
