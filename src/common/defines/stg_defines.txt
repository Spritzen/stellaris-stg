# ── CUSTOM_EMPIRE_SPAWN_CHANCE ─────────────────────────────────────────────
# Vanilla ships 50 on a `10 = 1%` scale (00_defines.txt:972): a 5% chance that
# any given AI slot is filled from the prescripted pool rather than randomly
# generated. 1000 is 100%, which is safe here only because decision 13 left the
# prescripted pool all-Trek and the 77 minor powers made it deep enough to
# fill a galaxy.
#
# IT WAS NEVER THE CAUSE. THREE galaxies were generated at 1000 and all three
# contained zero Trek AI empires; the galaxy only filled once STG shipped a
# static map (below). The define was a real defect and is a real fix. Do not
# read this file as the answer to "why is there no Trek in the galaxy", and do
# not raise or lower the value looking for one -- at 100% the draw rate is no
# longer the variable.
#
# The 2026-08-26 save takes the last excuse away: all 99 designs were loaded,
# `spawn_enabled=yes` on every one, and 1 of 77 countries in the galaxy was
# prescripted. Both levers are in and the pool is provably right, so whatever is
# left is neither of them.
#
# DO NOT TOUCH THIS VALUE AGAIN. STNH -- a Trek total conversion with a Trek
# galaxy, vendored at .source/688086068/ -- leaves this define at vanilla's 50
# and gets its empires from twenty-two static_galaxy_scenario maps instead. This
# lottery sprinkles the occasional preset into an otherwise random galaxy; it is
# not how a total conversion places a named cast.
#
# What DOES place them: the home system's initializer creates the empire with
# `create_country`, and a static_galaxy_scenario puts that system on the map.
# Vanilla's own com_sol_system does it for the United Nations of Earth. STG
# SHIPS THAT MAP NOW -- 95 systems, 21 empires -- and the 2026-08-27 Klingon run
# generated a galaxy holding 20 AI Trek empires, one each. The mechanism works
# and this define is not part of it.

# drawn from"

#
# This is the only lever of its kind: the designer's force-spawn checkbox exists
# for player-made empires and a prescripted one cannot reach it. CONFIRMED at the
# UI by the maintainer, 2026-08-26. Vanilla's loc strings say "template"
# (EMPIRE_SPAWN_ALLOWED / _DISALLOWED / _ALWAYS, and EMPIRE_SPAWN_TOOLTIP_DELAYED
# "Click to change the spawn setting for this empire template") and reading them
# as covering prescripted empires is wrong -- that inference was made and
# corrected on the same day. `spawn_enabled` in script is the only forcing lever
# STG has, and on the Federation's `always` it demonstrably does not fire.
# FALLEN_CUSTOM_EMPIRE_SPAWN_CHANCE stays at vanilla's 50 -- STG ships no
# prescripted fallen empire for it to find.
NGameplay = {
	CUSTOM_EMPIRE_SPAWN_CHANCE = 1000
}
