# Star Trek Galaxies -- Trek archaeological site types.
#
# A NEW file, not a shadow: site types merge by key across files, so vanilla's
# 327 are untouched and these 6 are added beside them. Stage events are in
# events/stg_arcsite_events.txt, pictures in interface/stg_arcsite_pictures.gfx,
# names, descriptions and stage prose in
# localisation/english/stg_archaeology_l_english.yml, and the finale modifiers
# in common/static_modifiers/stg_archaeology_modifiers.txt -- five files that
# must all meet, which is what check_archaeology asks.
#
# Every field, trigger, difficulty and idiom here is copied from
# common/archaeological_site_types/00_base_game_arc_sites.txt, whose header and
# 99_README_ARC_SITES.txt are the only documentation of the format.
#
# THESE SIX SPAWN ON SURVEY, which is the thing to understand before adding a
# seventh. `weight` is read only by `create_archaeological_site = random`, and
# the only thing in the game that calls it is events/
# ancient_relics_site_spawn_event.txt's ancrel.9999, hung on `on_survey_planet`.
# Its trigger asks nothing about DLC, so a weighted site reaches every host.
# Six of vanilla's ten base-game sites carry `weight = 0` and are placed by an
# initializer or an event instead; ours have nowhere to be placed FROM, because
# STG writes no story chain. See .docs/decisions/76-trek-archaeology.md.
#
# No `specimen`, no minor-artifact reward, no `has_ancrel` branch: STG is
# standalone and behaves the same whatever the host owns. Vanilla's own comment
# at the top of the base-game file says the same thing in the other direction --
# "a base-game arc site must offer a reward other than Minor Artifacts".
#
# `RANDOM_EVENTS = no_events` on all six, which is what vanilla's
# site_ancient_robot_world does. The alternative is one of the fifteen
# *_random_events effects in common/scripted_effects/archaeology_event_effects.txt,
# and every one of them fires `ancrel.*` dig-team events -- Ancient Relics
# content, guarded inside itself rather than at the call. The tooltip that tells
# the player their roll odds comes from standard_archaeological_site_on_roll_failed
# either way; only the interruptions are declined.
