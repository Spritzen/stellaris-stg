# Star Trek Galaxies -- the empire modifiers our archaeological sites end on.
#
# A NEW file, not a shadow: static modifiers merge by key across files, so
# vanilla's are untouched and these nine are added beside them.
#
# WHY OURS RATHER THAN VANILLA'S. The obvious shortcut is to reuse an existing
# modifier -- `ice_trauma_insights_colony` has exactly the effect the Lost
# Colony wants. It also has exactly the NAME "Frozen Submariners' Legacy", drawn
# on the player's modifier list under a Trek dig that has nothing to do with
# submarines. A static modifier is a loc key with numbers attached, and the loc
# key is the half that shows.
#
# Every modifier field below is copied from a vanilla static modifier that was
# opened in common/static_modifiers/02_static_modifiers.txt -- an invented field
# name is not an error, it is silently nothing.
#
# Magnitudes are deliberately near vanilla's own arc-site rewards
# (engineered_species_revelation is -10% species cost + 20% ethic attraction;
# ice_trauma_insights_colony is +20% colony development). Five of the six sites
# are `max_instances = 1`, so their modifiers are permanent (`days = -1`) the
# way vanilla's unique-site rewards are; the Lost Colony can recur, so its one
# is timed and cannot stack into an empire-wide bonus by digging.
#
# See .docs/decisions/71-trek-archaeology.md
