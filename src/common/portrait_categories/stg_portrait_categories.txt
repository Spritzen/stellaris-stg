# Star Trek Galaxies — the empire designer's portrait category for our species.
#
# New prefixed file, so it merges with vanilla's 00_portrait_categories.txt.
#
# Without this the sets in stg_portrait_sets.txt have no tab to live under in
# the empire designer, so a player building a custom empire cannot reach them —
# though the prescripted empires would still work.
#
# `name` is a localisation key, defined in
# src/localisation/english/stg_species_l_english.yml.

# One tab, not one per archetype: these have the Alpha Quadrant in common
# rather than an archetype, so BRG (MACHINE) and THO (LITHOID) sit here with the
# rest. A portrait category is a UI grouping and imposes no archetype
# constraint.
