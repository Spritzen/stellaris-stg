# Star Trek Galaxies — portrait sets for the major powers.
#
# New prefixed file, so it merges with vanilla's 00_portrait_sets.txt.
#
# The names in `portraits = { }` are portrait GROUPS, not individual portraits
# (vanilla's `humans` set lists "human" and "human_legacy"). Every group named
# below is declared by a vendored STNH file under gfx/portraits/portraits/.
#
# Clothing is not wired here. The vendored selectors pick a uniform from the
# species class and the STNH triggers in
# src/common/scripted_triggers/stg_stnh_art_triggers.txt, which have real bodies
# since .docs/decisions/16-phase-3-clothing-triggers.md. A species whose class no
# selector names falls through to human civilian clothes — `make validate`
# reports that, and it is not fixed in this file.

# ── The eight Walshicus-culture classes ────────────────────────────────────
#
# Without a set here the empire designer has no portrait to offer and hides the
# prescripted empire outright — seven of the nine that a live run caught that
# way, reported as `select_empire_design_view.cpp:714`.
#
# Pairings are STNH's own (sth_portrait_sets.txt) for KRE, MAL, SUL, VID, YRI,
# whose class tokens match ours. Three do not and are noted where they differ.
