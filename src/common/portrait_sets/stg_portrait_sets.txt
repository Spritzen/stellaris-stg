# Star Trek Galaxies — a portrait set for every STG species class.
#
# New prefixed file, so it merges with vanilla's 00_portrait_sets.txt.
#
# The names in `portraits = { }` are portrait GROUPS, not individual portraits
# (vanilla's `humans` set lists "human" and "human_legacy"). Every group named
# below is declared by a vendored STNH file under gfx/portraits/portraits/.
#
# Clothing is not wired here. The vendored selectors pick a uniform from the
# species class and the STNH triggers in
# src/common/scripted_triggers/stg_stnh_art_triggers.txt, which have real bodies
# since .docs/decisions/16-phase-3-clothing-triggers.md. A species whose class no
# selector names falls through to human civilian clothes — `make validate`
# reports that, and it is not fixed in this file.

# ── THE 77 MINOR POWERS ────────────────────────────────────────────────────
#
# A species class with no set here has NO PORTRAIT the empire designer can
# offer, and the designer answers that by hiding the empire — 'Must select a
# portrait'. That is not only a picker problem: decision 88 established that
# the picker and the galaxy generator read the same design database, so an
# empire hidden here cannot spawn as AI either.
#
# These were invisible to this rule while they carried `playable =
# stg_never`, because the check that enforces it skipped gated empires as
# unreachable. Removing the gate surfaced all of them at once.
#
# One class, one portrait group, taken from the empire's own `species` block in
# src/prescripted_countries/stg_z_minor_powers.txt — the 77 classes are
