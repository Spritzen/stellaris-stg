# Star Trek Galaxies — species classes for the major powers.
#
# New prefixed file, so it merges with vanilla's species class databases.
# KEYS ARE DELIBERATELY UNPREFIXED: the vendored STNH clothing selectors gate
# every Trek uniform on `is_species_class = FED / VUL / KDF / …` and cannot be
# edited. See .docs/decisions/10-species-class-keys-unprefixed.md.
#
# The same rule binds the SPELLING, not just the absence of a prefix. Eight
# minor powers here carry STNH's key rather than a plausible one of our own —
# BEN not BENZ, DEN not DENO, HYDR not HYD, KES not KESS, NYG not NYGE,
# TEL not TELL, TUR not TURE, VAU not VAUN — because the master clothes
# selectors name those eight and a near miss dresses the species in human
# civilian clothes. See .docs/decisions/20-minor-power-species-class-keys.md.
#
# Archetypes are vanilla's. STNH's own (HUMANOID, CRYSTALLINE, CHANGELING,
# SYMBIONT) are defined in its common/species_archetypes/, which we do not
# vendor — naming one here gets the class silently dropped.
#
# `graphical_culture` names a vendored ship set, and comes from one of two
# places. Most name a Walshicus standalone shipset, which declares its own
# culture and all 44 of vanilla's section entities — nothing of ours is
# involved. Five (BAJ, TRI, ADR, BOL, BRE) have no such set and stay on STNH
# art, whose culture and vanilla-shaped entities are generated into src/ by
# tools/gen_shipsets.py, as do the generic_0N donor cultures the AI-only minors
# share. Either way the key is the art's to choose, not ours, for the same
# reason these keys are unprefixed.
# See .docs/decisions/18-walshicus-shipsets-replace-stnh-hulls.md.
#
# `randomized = no` throughout: these appear only as the prescripted empires in
# src/prescripted_countries/, and 31 of the 131 are selector stubs that no
# empire names at all -- .docs/decisions/32-declare-stub-species-classes.md.

# STUBS FOR CLASSES THE VENDORED ART NAMES AND NO EMPIRE OF OURS DECLARES.
#
# STNH's master clothes selectors gate 439 wardrobe branches on these 30 keys.
# Undeclared, each one is a `Failed to deferred read key reference` at load --
# 439 records in the 2026-08-07 run, 22% of error.log -- and the species that
# would have worn them falls through to the selector's `default`, i.e. human
# civilian clothes. Declaring the key is what makes the reference resolve;
# see .docs/decisions/10-species-class-keys-unprefixed.md.
#
# `graphical_culture = generic_01` throughout, and it is INERT: no empire
# declares these classes, so nothing ever resolves ship art through them. A kin
# culture is not guessed here rather than asserting a relationship the sources
# do not state.
#
# Spelling is STNH's, not ours, for the same reason the keys are unprefixed --
# and four of these keys REPLACED a near miss of our own (DELT->DEL,
# ELAU->ELA, MONE->MON, PARA->PAR), which is decision 20 applied again.
# ============================================================================
