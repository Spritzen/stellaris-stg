##########################
#
# Star Trek Galaxies -- stage events for the Trek archaeological sites in
# common/archaeological_site_types/stg_arc_sites.txt.
#
# SCOPES, from events/arcsite_events.txt, which every one of these copies:
#   this  = the excavating fleet     from   = the archaeological site
#   owner = the excavating country   leader = its scientist
#   from.planet = the body being dug
#
# `archaeology = yes` is what puts the popup in the dig-site frame rather than
# the ordinary event frame. `set_site_progress_locked` in `immediate` and back
# in `after` is vanilla's own bracket -- without it the excavation can roll the
# next stage while the player is still reading this one, and `after` rather than
# an option effect because an option with a `trigger` can be the one not taken.
#
# The `if = { limit = { NOT = { has_deposit_for = shipclass_research_station } }
# clear_deposits = yes }` before a research deposit is vanilla's, for the reason
# .docs/decisions/75-trek-anomalies.md records: without it the body keeps a
# deposit that makes the research station unbuildable and the reward is
# unreachable.
#
# No `specimen`, no minor artifacts, no `has_ancrel` branch: STG is standalone.
# See .docs/decisions/76-trek-archaeology.md
#
##########################
