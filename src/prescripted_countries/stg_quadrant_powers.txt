# Star Trek Galaxies — the nine powers that fill out the quadrant.
#
# Phase 2's first bullet (.docs/planning/phases.md). New prefixed file, merging with
# stg_major_powers.txt beside it; between them they are the whole empire picker.
#
# The game does not report an invalid prescripted empire — it refuses to start,
# or quietly drops the entry — so every authority / government / civic / ethic
# here was read against the `possible` block of the thing it names. The
# constraints that actually bind:
#
#   auth_democratic       forbids ethic_(fanatic_)authoritarian
#   auth_oligarchic       forbids ethic_fanatic_egalitarian AND
#                                 ethic_fanatic_authoritarian
#   auth_dictatorial      forbids ethic_(fanatic_)egalitarian
#   auth_imperial         forbids ethic_(fanatic_)egalitarian
#   auth_machine_intel.   REQUIRES ethic_gestalt_consciousness and a species
#                                 whose archetype is MACHINE
#
#   gov_trade_league            is_megacorp + civic_free_traders|trading_posts
#   gov_theocratic_republic     is_democratic_authority + is_spiritualist
#   gov_direct_democracy        is_democratic_authority + is_materialist
#   gov_moral_democracy         is_democratic_authority + is_pacifist
#   gov_citizen_stratocracy     is_oligarchic_authority + civic_citizen_service
#   gov_irenic_bureaucracy      is_oligarchic_authority + is_pacifist
#   gov_military_dictatorship   is_dictatorial_authority + is_militarist
#   gov_divine_empire           is_imperial_authority + civic_imperial_cult
#   gov_machine_assimilator     is_machine_empire + civic_machine_assimilator
#
# Trait budgets are the vanilla default of 2 points and every list below sums
# to exactly 2. Archetype matters: trait_adaptive, trait_slow_breeders and
# trait_fleeting are BIOLOGICAL-only, so the Tholians take lithoid-legal traits
# and the Borg robot ones.
#
# `initializer =` names a real home system, as for the majors — see the header
# of stg_major_powers.txt and .docs/decisions/25-real-home-systems.md.
# `graphical_culture` is
# set HERE TOO and overrides the species class, so it must match
# stg_species_classes.txt — remapping one without the other silently drops the
# empire to `fallback = mammalian_01`. Four of these nine are on Walshicus
# shipsets and five (BAJ, TRI, ADR, BOL, BRE) are still on STNH art through
# tools/gen_shipsets.py; see
# .docs/decisions/18-walshicus-shipsets-replace-stnh-hulls.md.
# `city_graphical_culture` names one of STNH's Trek city sets where it ships one
# (borg_01, tholian_01, undine_01) and vanilla's otherwise — which STNH re-skins
# anyway. Flags are vendored STNH heraldry at flags/trek/, the Bolians excepted:
# STNH ships none, and neither does any Walshicus shipset.
# See .docs/decisions/49-flags-city-sets.md.

# `room =` is STNH's own assignment for the same empire, restored 2026-08-08 by
# tools/fix_prescripted_rooms.py — it had been replaced wholesale by vanilla
# personality rooms, which cost the 20 empires STNH gives a Trek room. The three
# rows where STG keeps its own answer are listed in that script.
# See .docs/decisions/48-room-selector-merge.md
