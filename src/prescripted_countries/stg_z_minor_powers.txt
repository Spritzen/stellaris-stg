#
# Converted from STNH's own prescripted countries: their IDENTITY is STNH's --
# name, species, homeworld, ruler, heraldry, name list -- and their MECHANICS are
# not. All 110 of STNH's use at least one STNH-only origin, trait, civic or room
# and not one validates against vanilla 4.4 as written, so every
# authority/government/civic tuple below is lifted whole from a vanilla
# prescripted empire and matched by ethics, exactly as stg_frontier_powers.txt
# does. .docs/decisions/19-stnh-minor-powers-as-ai-empires.md
#
# See stg_major_powers.txt's header for the per-field notes and
# .docs/reference/prescripted-empire-rules.md before editing any empire here.
#
# ALL 77 ARE PLAYABLE, and that is not a preference. `playable` gates the
# engine's empire-design DATABASE, not the picker, and the galaxy generator draws
# from that same database -- so a gated empire is in neither. There is no AI-only
# prescripted empire in Stellaris.
# .docs/decisions/88-playable-gates-the-design-database.md
#
# SHIP ART, and the reason this file was affordable at all: 34 of the 77 keep
# their own STNH culture, because it is one of generic_01/02/05/06/07 -- already
# harvested as donor art and declared as cultures by tools/gen_shipsets.py. The
# other 43 point at a Walshicus set instead of their own STNH directory. A Gorn
# empire flying Xindi hulls is wrong; the alternative was 38 more STNH
# directories and ~5,800 log records for empires you mostly meet as a portrait.
# .docs/decisions/19-stnh-minor-powers-as-ai-empires.md
#
# GENERATED SHAPE, HAND-OWNED FILE: written once by a throwaway script from
# .source/, then owned here. Regenerating it is not part of `make vendor`.
