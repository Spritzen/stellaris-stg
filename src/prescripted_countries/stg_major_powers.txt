# Star Trek Galaxies — the five major powers.
#
# One of four prescripted-empire files that merge into the whole empire picker;
# vanilla's 52 are removed by the 19 comment-only shadow files here
# (.docs/decisions/14-remove-vanilla-prescripted-empires.md) and default.txt is
# untouched, so custom empire creation still works.
#
# BEFORE EDITING ANY EMPIRE HERE, read
# .docs/reference/prescripted-empire-rules.md. Five databases can veto a
# prescripted empire, the game reports none of them, and it holds the
# authority/government/trait tables plus the three fields that resolve by bare
# name and fail silently.
#
# Per-field notes, none of which the rules doc covers:
#
#   initializer         a REAL home system, GENERATED into
#                       src/common/solar_system_initializers/stg_home_systems.txt
#                       by tools/gen_home_systems.py. planet_name/planet_class
#                       still override the initializer's capital, as vanilla's
#                       own plantoid_humans does with Sol.
#                       .docs/decisions/25-real-home-systems.md
#   graphical_culture   all five majors are on Walshicus shipsets --
#                       .docs/decisions/18-walshicus-shipsets-replace-stnh-hulls.md
#   empire_flag         vendored STNH heraldry at flags/trek/ --
#                       .docs/decisions/49-flags-city-sets.md
#   room                STNH's own assignment, rewritten by
#                       tools/fix_prescripted_rooms.py --
#                       .docs/decisions/48-room-selector-merge.md
#   ruler.clothes       ABSENT on 92 of the 99 empires, deliberately: a pinned
#                       ruler keeps that index for life while every other leader
#                       re-evaluates the selector.
#                       .docs/decisions/57-prescripted-rulers-unpin-clothes.md
#                       THE SEVEN THAT PIN `clothes = 0` name a GENERATED
#                       `stg_*_ruler` portrait carrying a one-texture selector,
#                       so index 0 IS the intended garment. Written by
#                       tools/gen_ruler_clothes.py.
#                       .docs/decisions/69-ruler-clothes-dedicated-selectors.md
#   ruler.texture       `= 0` stays -- the one index with a declared length to
#                       check.
