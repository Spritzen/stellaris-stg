# 48 — Paragon leader backgrounds: declare our own rather than un-exclude STNH's

**Resolved 2026-08-08.** Closes the last item in plan.md §6 Phase 3's
"Outstanding" list.

## The standing note, and why it was half right

plan.md said:

> `gfx/portraits/asset_selectors/paragon_backgrounds.txt` — per-era Starfleet
> leader backgrounds. STNH's was excluded because every entry gated on triggers
> we do not vendor. Its 52 textures were pruned by Phase 5's closure and are
> still in `.source/`; **they return by themselves the moment a selector names
> them.**

The last clause is exactly right and was demonstrated: naming 23 of them dropped
the prune count from 990 to 967 with no edit to `vendor.yml`.

The first clause is stale in one direction and wrong in another. Of the 32
triggers STNH's file uses, **31 are now declared** — decision 15 gave them
bodies after the exclusion was written. But declared is not the same as true:

```
is_earth_or_ufp_story_empire = { always = no }   # every Federation row
uses_command_background      = { always = no }   # every admiral row
is_army_leader               = { always = no }   # every general row
is_security_leader           = { always = no }
```

Those four are on decision 15's **INERT** list on purpose, and turning them on
would change the *clothing* selectors that share them. So un-excluding STNH's
file would have reached almost nothing — while dropping vanilla's four legendary
paragon rows (`legendary_bg_azaryn`, `_beholder`, `_skrand`, `_keides`), because
it shadows vanilla's path. Decision 07's failure mode, bought for no gain.

## There is a second file, and it is in a directory we do not take

A background name is not a texture path. The selector says `X`; the engine looks
up the sprite `GFX_leader_X`; the sprite names the `.dds`. Vanilla declares its
own in `interface/portraits/leaders.gfx`, and STNH declares its 52 in
`interface/STH_asset_selector_images.gfx` — `interface/` being one of the four
directories plan.md §3 never takes from STNH.

So even a perfect selector reaches nothing without the sprites. This is decision
33's shape again: *a declaration name is not a filename — resolve the
indirection, then ask the question.*

## What STG ships

Two files, both generated by `tools/gen_paragon_backgrounds.py`:

- **`src/gfx/portraits/asset_selectors/paragon_backgrounds.txt`** — vanilla 4.4
  verbatim, its four legendary rows kept, plus 28 STG rows gated on species class
  and leader class. STNH's copy stays excluded.
- **`src/interface/stg_paragon_backgrounds.gfx`** — a NEW file, not a shadow: 28
  `spriteType`s pointing at STNH's textures under `gfx/portraits/leaders/`.
  "Declare, don't shadow", per plan.md §4.

The selector keys take the `stg_` prefix. Decision 09's exception does not apply
here — no vendored art references these names, we invented them, so the ordinary
rule holds.

**Row order is load-bearing and was got wrong first.** A selector takes the first
row whose trigger passes, and vanilla's `bg_admiral = { leader_class = commander }`
passes for every commander in the game. Inserted below it — which is where an
"append before the catch-all `default_background`" reading puts them — none of
the Trek rows could ever have fired, and nothing would have logged it. The
generator anchors on the *first* catch-all in each scope, and says so.

## The mapping, and the three gaps in it

| class | commander | scientist | official | ruler |
|---|---|---|---|---|
| FED | `admiral_federation_tng` | `scientist_federation_tng` | `governor_federation` | `ruler_federation` |
| KDF / ROM / CAR / DOM | that people's `admiral_*` | `scientist_*` | `governor_*` | — |
| FER | `admiral_ferengi` | `admiral_ferengi` | `governor_ferengi` | `governor_ferengi` |
| BRG | `all_borg` | `all_borg` | `all_borg` | `all_borg` |
| TER | — | — | `governor_terran` | `ruler_terran` |
| CON | — | — | `governor_confederation` | `ruler_confederation` |

23 of STNH's 52 textures are reached. The 29 that are not, and why each is not an
omission:

- **The `general_*` set (9).** 4.x folded the army general into `commander`;
  there is no leader class left to gate on.
- **The Federation's other seven eras** (`ent`, `kel`, `dis`, `snw`, `tos`,
  `wok`, `fco`, `pic`). STG starts at TNG/DS9 and stays there — decision 15 —
  so the `_tng_` cut is the one that applies.
- **`ruler_earth_bg` / `governor_earth_bg`.** STG has no United Earth, only the
  Federation it became.
- **`leader_scientist_ferengi_bg.dds` does not exist**, in STNH either. STNH's
  own `.gfx` points its Ferengi scientist sprite at the admiral texture; this
  does the same, rather than inventing a row or dropping one.

Klingon, Romulan, Cardassian and Dominion rulers fall through to vanilla's
`bg_ruler`: STNH cut no ruler plate for them.
