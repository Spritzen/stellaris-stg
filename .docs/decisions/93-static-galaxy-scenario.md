# 93 — The country flag is what joins a static map to an empire, and `prescripted_flags` is the half nobody had written

**Status:** decided, 2026-08-27
**Follows** [decision 92](92-create-country-initializers.md), which found that an
AI Trek empire is created by its home system's initializer, and
[decision 91](91-static-galaxy-is-the-mechanism.md), which found the static map.
**Completes** [the plan](../planning/static-galaxy-plan.md)'s pieces 1, 2 and 4;
piece 3, locking the picker, stays deliberately undone.
**Corrects** [the plan](../planning/static-galaxy-plan.md)'s reading of STNH's
hyperlane parameters, which said all 21 lane-less maps pair
`random_hyperlanes = no` with `num_hyperlanes = { min = 0 max = 0 }`. Ten do;
the rest carry a live range or no `num_hyperlanes` line at all.

## What was settled first, because everything hung off it

**`spawn_weight` with a country flag, not `spawn_design`.** The plan made this
question one, and the evidence is one-sided:

| | `spawn_weight` + `has_country_flag` | `spawn_design` |
|---|---|---|
| STNH, 22 static maps | 99–152 systems per canon map | **0 uses** |
| vanilla | `static_galaxy_example.txt` documents both | documented, unused |
| what it needs to work | a country carrying a flag — which the initializer's own `create_country` sets | the design database to hand out a prescripted design |

`spawn_design` routes back through the draw that produced six empty galaxies
([90](90-design-database-is-not-the-cause.md)). `spawn_weight` needs nothing but
a country flag, and the initializer that creates the empire sets that flag
itself. It is also the only one of the two with a shipping precedent.

## The finding: the player's copy needs the flag too, and only one database gives it

STNH's Qo'noS initializer creates the Klingon Empire behind

```
if = { limit = { NOT = { any_country = { has_country_flag = klingon_empire } } } … }
```

and `set_country_flag = klingon_empire` appears in exactly one place in their
whole tree — inside that same `create_country`. So on the reading decision 92
left, the guard could never see a *player* who had picked the Klingons, and
picking them would put a second Klingon Empire on Qo'noS.

**It does see them, and the mechanism is `common/prescripted_flags/`.** Vanilla:

```
/stellaris/prescripted_countries/00_top_countries.txt      humans2 … flag = empire_human_2
/stellaris/common/prescripted_flags/00_default_empire_flags.txt:5
        empire_human_2 = { flags = { human_2 custom_start_screen } }
```

The entry's flags are set on the country when it is created, before a single
system exists. STNH ships the same thing —
`STNH_default_empire_flags.txt:17`, `empire_KlingonEmpire = { flags = {
custom_start_screen klingon_empire … } }` — which is where the player's
`klingon_empire` comes from.

**And vanilla proves the ordering on disk, which is what makes the guard
answerable at all.** `com_sol_system` decides whether to exist by asking about
playable countries *during galaxy generation*:

```
/stellaris/common/solar_system_initializers/sol_initializers.txt:830
    usage = misc_system_init
    usage_odds = { base = 0 modifier = {
        any_playable_country = { is_human_species = yes
            OR = { has_country_flag = human_2 has_country_flag = human_3 } } … } }
```

Countries exist, and carry their prescripted flags, before initializers run.

**STG shipped neither half.** No `common/prescripted_flags/` directory, and no
`flag =` line on any of the 99 empires. That is now
`src/common/prescripted_flags/stg_empire_flags.txt`, generated by
[`tools/gen_empire_flags.py`](../../tools/gen_empire_flags.py), plus one
hand-authored `flag = empire_<key>` line per empire.

**The country flag is the design key.** `stg_klingon_empire` is the prescripted
block key, the country flag, the string the map's `spawn_weight` tests and the
string the initializer sets — one name to get wrong instead of three.

## What shipped

| Piece | Where | How |
|---|---|---|
| the flag join | `src/common/prescripted_flags/stg_empire_flags.txt` — 99 entries | generated ([`gen_empire_flags.py`](../../tools/gen_empire_flags.py)) |
| | `flag = empire_<key>` on all 99 prescripted empires | hand-authored, checked |
| the AI copies | 36 `create_country` blocks in `src/common/solar_system_initializers/stg_home_systems.txt` | generated ([`gen_home_systems.py`](../../tools/gen_home_systems.py), `ai_empire_block`) |
| the map | `src/map/setup_scenarios/stg_alpha_beta_quadrant.txt` — 95 systems, 21 empires | generated ([`gen_static_galaxy.py`](../../tools/gen_static_galaxy.py)) |
| the check | `check_static_galaxy` in [`tools/validate.py`](../../tools/validate.py) | five questions, vanilla floor 0 |

**The `create_country` body is vanilla's recipe, not STNH's.** `com_sol_system`
creates the United Nations of Earth with `create_country`, `create_colony`,
`generate_start_deposits_and_blockers`, `clear_blockers`, start buildings and
pops, `create_starting_leaders`, then `game_start.9` and `game_start.33`. No
`create_starbase`: vanilla's own comment on the one-day delay — *"needs delay
for system ownership to settle"* — says `create_colony` establishes the system.
STG's blocks are that sequence with the empire's own identity transcribed out of
its `prescripted_countries/` entry.

**One line is borrowed from STNH rather than derived from vanilla, and is
labelled in the generator because of it:** `ideal_planet_class` inside
`create_species`'s `traits`. Vanilla gives a created species its habitability
through a `trait_pc_*_preference` trait; STG's prescripted empires carry none,
because a prescripted empire declares `planet_class` instead and `create_species`
has no such field. STNH writes `ideal_planet_class` in 42 initializer files on
this same 4.4.6. **If a live run shows AI empires with the wrong habitability,
that is the line that did not take.**

## The map, and where every coordinate came from

`stg_alpha_beta_quadrant.txt` is **95 systems, 21 of them an empire's home**,
which is STNH's own density — their smallest canon map, `09 botf`, is 468 stars
for 99 weighted systems, 4.7 per empire against our 4.5.

**Nothing in it is invented.** Every position is harvested from STNH's
`01 STH_galaxy_default_galaxy_map.txt` and scaled by 0.36: the 21 home systems
from the initializer each empire's home was converted from, the other 74 by
thinning the same map's remaining 1,415 positions to a minimum separation. The
result has a radius of 218 and a median nearest-neighbour distance of 26 units,
against vanilla's own `max_hyperlane_distance = 50` — so no system is stranded.

The header is `04 STH_galaxy_tiny_alpha_beta`'s, the closest thing in `.source/`
to what this is. Two of its values are the design rather than convention:

- **`num_empires = { min = 0 max = 0 }`.** Every empire in the galaxy comes from
  an initializer, so no randomly generated non-Trek empire can appear. Nine of
  STNH's 22 maps set it.
- **`random_hyperlanes = no` and no `add_hyperlane` line anywhere.** 21 of
  STNH's 22 define no lanes; only the BotF map does, with 892. `num_hyperlanes`
  is the density the setup screen offers, and 04's `{ min = 0.5 max = 1.0 }` is
  the safer of the two shapes in use while nobody here has watched a static map
  generate. **This is the single largest unknown in what shipped** — see below.

`default = yes` is **not** set. Ariphaos Galaxies' `medium.txt` already carries
it and two defaults is worse than none; it belongs with the picker lock.

## Two empires are deliberately absent, and both are content calls

**The Terran Empire.** Its home system is Sol and its capital is Earth — the
same two names as the Federation's, which never collided before because no
galaxy had ever placed both. STNH puts the Terran Empire in its five *mirror*
maps and in no prime-universe map at all. It stays out of this one, and belongs
to a mirror scenario when there is one.

**An AI Federation.** Sol here is `sol_system_initializer`, which is **Real
Space's** file, not ours — so there is nowhere to put a `create_country` for the
Federation without either taking an `src/` override of that file or a
`vendor.yml` patch into it. The player's Federation still starts at Sol and the
map still pins it there; nobody else plays it yet. **This is the one empire in
the map whose AI copy does not exist, and it is the most visible one**, so it is
the first thing to fix after the mechanism is graded. The two candidates are a
`patches:` insertion into Real Space's Earth `init_effect`, and an STG-owned Sol
generated from Real Space's geometry with the prescripted Federation repointed
at it — the second is cleaner and costs [decision 25](25-real-home-systems.md)'s
"pointing at it beats reproducing it".

## The check, and what calibrating it found

`check_static_galaxy` asks five questions of every scenario in the merged tree:
initializers and `spawn_design`s resolve; every country flag a `spawn_weight`
tests is reachable, from `set_country_flag` *or* from `prescripted_flags`; no two
systems share an id or a position; hyperlane endpoints are declared and, **where
a scenario defines lanes at all**, the graph is connected; and every
`flag = empire_X` resolves to an entry that carries the design's own key.

**Vanilla's floor is 0 and Ariphaos's is 0.** One condition is scoped to `stg_*`
keys and the scope is a calibration result: *"the flag is the design key"* is
our convention, and vanilla's own roster answers it 21 times out of 51 without a
defect in sight.

**STNH's 22 maps report 4,265 findings against their own tree** — 4,256 systems
naming one of 38 initializers nothing in the mod declares (`rl_sirius` is a
`name = "…"` inside a different initializer; `sck_b` does not exist), 8
`spawn_weight`s on a country flag nothing sets, one prescripted design pointing
at a missing `prescripted_flags` entry. Every one of those is an empire that
quietly does not appear, in the shipping mod this whole mechanism is modelled
on. It is a reason to keep the check strict, not to widen it.

**And the check was calibrated by breaking things, not by reading it**
([rule 7](../validation/check-design.md#7-compare-declared-identity-not-block-key--and-distrust-a-check-that-has-never-failed)):
ten mutations of the shipped scenario and the flags file — a typo in an
initializer, a flag nothing sets, a duplicated id, a duplicated position, an
unknown `spawn_design`, two lanes making two components, a lane to a system that
does not exist, a missing `prescripted_flags` entry, an entry setting the wrong
flag — and each one is reported.

## One latent defect fell out of writing this

`_initializer_class_tokens` and `_star_planet_count` in `tools/validate.py`
walked `key = {` with a **lowercase-only** pattern while popping on every `}`.
`NOT = {`, `OR = {` and `AND = {` therefore popped without pushing, and the
block stack drifted one level shallower for the rest of the file. Nothing in an
initializer used to open a `limit = { NOT = { … } }` beside a `class =`; the AI
guards do. The same bug was in `check_references` in `gen_home_systems.py`, where
it would have miscounted stars. Both fixed; neither changes a single finding
today, which is the point — it was waiting for the file that would trip it.

## What this closes, and what it does not

**Closes** the plan's pieces 1, 2 and 4, and the question of which binding to
use.

**Does not close** the six-galaxy question. Nothing here is verified in game:
`make validate` is clean, `make gen-check` is 13 of 13 fixpoints, and both were
clean throughout every one of the six empty galaxies. **The next live run is the
whole test** — select *The Known Galaxy* in the galaxy-shape picker, and the
question is whether the galaxy contains 20 Trek AI empires or one player and
nothing else.

**Does not close** the picker lock, on purpose. The plan is explicit that it
comes after a scenario is known to be playable — locking it now would leave a
player with fourteen removed scenarios and one unproven one.

**Does not close** whether the prescripted *pool* can ever be drawn from. That
stays open with `randomized` as its suspect
([90](90-design-database-is-not-the-cause.md),
[91](91-static-galaxy-is-the-mechanism.md)); the 99 remain the player's roster.
This makes it stop gating the galaxy.

## What to watch for on the run, in the order it would fail

1. **Does the scenario appear in the picker at all**, and does its name render
   rather than showing `STG_galaxy_alpha_beta`?
2. **Does the galaxy generate?** A static map with no defined lanes is the shape
   nobody here has watched run. If it generates with no hyperlanes, or hangs,
   `num_hyperlanes` is the dial and `09 botf`'s 892 hand-cut lanes are the
   fallback.
3. **Count the empires.** 20 AI empires is the mechanism working. One is the
   `create_country` blocks never running. A handful means some initializers
   failed and `error.log` will name them.
4. **Play the Klingons and count the Klingon Empires.** Two means the
   `prescripted_flags` guard did not fire, which is the one thing in this
   decision that vanilla proves indirectly rather than directly.
5. **Look at an AI empire's homeworld and its species' habitability** — that is
   the `ideal_planet_class` line.
6. **`/paradox/stellaris/logs/error.log`**, for `Invalid initializer` and for
   anything naming `stg_home_systems.txt` ([procedure](../guides/live-runs.md)).
