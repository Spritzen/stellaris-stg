# Repo layout

> **What** — every top-level path, what generates it, and what may be hand-edited.
> **Open when** — looking for where something lives, or before creating a file
> anywhere new.
> **Then** — [Vendored merge](../architecture/vendored-merge.md) · [Writing script](../guides/writing-script.md) · [Documentation map](../README.md)

```
vendor.yml              source mods, harvest order, includes/excludes, merge decisions,
                        patches, renames, clutter_keep and the *_ack lists
sources.lock.yml        GENERATED by make sources-sync; which revision of each source is pinned
.source/                GENERATED by make sources-sync; the pinned source mods. Not hand-edited.
  <workshop-id>/        a byte-exact mirror of /workshop/<workshop-id>
  .meta/<id>.json       per-file hashes, for `make sources-status DEEP=1`
src/                    hand-written STG content — mirrors the game's tree, applied last
  descriptor.mod        the mod's own descriptor; vendored into stg-build/
  thumbnail.png
                        — three kinds of file, and the kind decides the filename:
  stg_*                   OUR content. Species classes, 92 name lists, the 101
                          prescripted empires, loc, the STNH art triggers and traits,
                          the graphical cultures, the music declarations.
  stg_*.asset / .gfx      DECLARE-don't-shadow: a new filename adding what a vendored
                          file lacks — the four restores, the two Real Space forks,
                          and zz_stg_shipsets.asset.
  <vanilla_name>.txt      SHADOWS vanilla or a source outright — the two merges,
                          pdxmesh.shader, the pruned URP topbar file,
                          sth_soundgroups.asset, and 19 comment-only prescripted-empire
                          files that exist to delete vanilla's (decision 14). A header
                          comment saying what it overrides and why is required, and
                          make validate enforces it.
tools/
  sources.py            snapshots /workshop into .source/; status and diff against it
  vendor.py             replays vendor.yml into the tree, out of .source/, then prunes
  clutter.py            the reachability closure — `make clutter`, and the prune scope
  validate.py           BOM/syntax + vendored checksums + the cross-reference family
  check_docs.py         every .docs/ link and code citation resolves — `make docs`
  deploy.py             symlinks stg-build/ into the Paradox mod folder; writes the .mod
  gen_shipsets.py       one-shot: graphical cultures + vanilla-shaped ship entities
                        (decision 17, narrowed by 18 to the five cultures with no
                        Walshicus set, plus the generic_* minor-power donors)
  gen_home_systems.py   one-shot: the 37 home systems (decision 25)
  gen_borg_vo.py        one-shot: src/sound/sth_soundgroups.asset
  gen_room_selector.py  the one room_selector: vanilla + STNH's 47 Trek rooms
                        + Diverse Rooms' designer list (decision 48)
  gen_paragon_backgrounds.py  the paragon leader backgrounds and their sprites
                        (decision 50)
  gen_star_names.py     one-shot: 829 Trek star + 80 nebula names harvested from
                        STNH's hand-built map/setup_scenarios (decision 52)
  gen_ship_names.py     the ship_names pools: STNH's 38,707 registry names
                        folded onto vanilla's ship sizes (decision 59)
  gen_ruler_clothes.py  the seven empire-select ruler portraits and their
                        one-texture clothes selectors (decision 69)
  fix_ship_locators.py  weapon mount positions (decisions 28, 60, 67)
  fix_prescripted_rooms.py    rewrites `room =` from STNH's own assignment
                        — all of these read .source/, never the built tree
.docs/                  documentation — see .docs/README.md for the map
stg-build/              GENERATED by make vendor — the mod itself. Do not hand-edit.
.vendor-manifest.json   GENERATED by make vendor; per-file provenance, ~6 MB
.vendor-cache/          GENERATED by make vendor; unpacked source zips and the
                        generators' scratch data. Safe to delete; rebuilt on demand.
dist/                   GENERATED by make dist — the archive zip. Nothing reads it.
.devcontainer/          container definition, not shipped
dotnet/                 .NET SDK scratch cache, created by editor tooling in the
                        container. Not a build input, not shipped, safe to delete.
```

## What is generated and what is not

| Path | Generated by | Hand-edit? |
|---|---|---|
| `vendor.yml` | — | **yes**, it is the manifest |
| `src/` | — | **yes**, this is our content |
| `.docs/` | — | **yes**, except `provenance.md` |
| `sources.lock.yml` | `make sources-sync` | no |
| `.source/` | `make sources-sync` | **no** — mirrors upstream |
| `stg-build/` | `make vendor` | **no** — `make validate` fails on it |
| `.docs/provenance.md` | `make vendor` | no |
| `.vendor-manifest.json` | `make vendor` | no |
| `.vendor-cache/` | `make vendor` | no |
| `dist/` | `make dist` | no |
| `dotnet/` | editor tooling | no |

Git tracks only `vendor.yml`, `src/`, `sources.lock.yml`, `tools/`, `.docs/`,
`Makefile` and the container definition. Everything generated is ignored, and
`.gitignore` is the authority — read it rather than this paragraph.

The mod is one directory, so the Paradox mod folder is one symlink to it and
`make dist` zips it whole —
[decision 13](../decisions/13-build-dir-and-symlink-deploy.md).
