## Keeping these honest

**A stale plan is worse than none.** When you find one of these contradicted by
what is actually on disk, fix the document — that is not a digression from the
task, it is part of it.

Every number in here carries a date, because every number in here goes stale
([style guide §6](../style-guide.md#6-numbers-get-a-date-and-a-source)). Where a
figure can be re-measured from the build, the document says how rather than
asserting it.
